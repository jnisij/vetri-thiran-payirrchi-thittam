# Phase 4 – Project Planning

## Project Title
Auto Ticket Classification using Flow Designer

## Project Goal
To develop an automated ticket classification system using ServiceNow Flow Designer.

## Project Plan

### Step 1 – Project Setup
Create and configure the ServiceNow project environment.

### Step 2 – Table Creation
Create a custom table to store ticket records.

### Step 3 – Field Configuration
Create and configure the required ticket fields.

### Step 4 – Choice Configuration
Configure category, subcategory, and state values.

### Step 5 – Flow Designer
Create the required automation using Flow Designer.

### Step 6 – Ticket Creation
Create sample ticket records for testing.

### Step 7 – Testing
Test the automated ticket classification process.

### Step 8 – Documentation
Prepare the project documentation and screenshots.

### Step 9 – Demonstration
Record the final project demonstration video.
