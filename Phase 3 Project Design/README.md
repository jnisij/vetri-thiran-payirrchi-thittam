# Phase 3 – Project Design

## Project Title
Auto Ticket Classification using Flow Designer

## System Design

The project is designed using ServiceNow and Flow Designer to automate the ticket classification process.

## Main Components

1. Ticket Table
2. Ticket Fields
3. Category
4. Subcategory
5. State
6. Flow Designer
7. Automated Ticket Processing

## Basic Workflow

User creates a ticket
        ↓
Ticket details are stored
        ↓
Flow Designer is triggered
        ↓
Ticket is processed
        ↓
Classification is applied
        ↓
Updated ticket is displayed

## Technology Used

- ServiceNow
- Flow Designer
