# Phase 2 – Requirement Analysis

## Project Title
Auto Ticket Classification using Flow Designer

## Functional Requirements

1. The system should allow users to create ticket records.
2. The system should store ticket details in the ServiceNow table.
3. The system should provide category and subcategory fields.
4. The system should provide a state field for tickets.
5. The system should automatically process tickets using Flow Designer.
6. The system should display the processed ticket information.

## Non-Functional Requirements

1. The system should be easy to use.
2. The system should reduce manual work.
3. The system should process tickets efficiently.
4. The system should maintain organized ticket records.

## Tools and Technologies

- ServiceNow
- Flow Designer

## Expected Outcome

The system should automate the ticket classification process and make ticket handling easier and more organized.
