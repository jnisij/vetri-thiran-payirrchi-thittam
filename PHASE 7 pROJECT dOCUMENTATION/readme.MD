# Phase 7 – Project Documentation

## Project Title
Auto Ticket Classification using Flow Designer

## 1. Project Overview
This project automates the ticket classification process using ServiceNow Flow Designer.

## 2. Problem Statement
Manual ticket classification can require time and effort. This project aims to automate the process.

## 3. Objectives
- Automate ticket classification
- Reduce manual work
- Organize ticket information
- Improve ticket handling

## 4. Technologies Used
- ServiceNow
- Flow Designer

## 5. Project Implementation
A custom ticket table and required fields were created in ServiceNow. Flow Designer was used to automate the ticket classification process.

## 6. Testing
The project was tested using sample ticket records and the classification workflow was verified.

## 7. Result
The system processes ticket information through the configured workflow and produces the expected classification result.
