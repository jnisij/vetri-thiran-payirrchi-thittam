# Phase 1 – Brainstorming and Ideation

## Project Title
Auto Ticket Classification using Flow Designer

## Problem Statement
Manual ticket classification can take time and may lead to incorrect categorization. The project aims to automate ticket classification using ServiceNow Flow Designer.

## Idea
The idea is to create an automated ticket classification system in ServiceNow using Flow Designer.

## Objective
- Automate ticket classification
- Reduce manual work
- Improve ticket handling
- Organize ticket information efficiently

## Proposed Technology
- ServiceNow
- Flow Designer
